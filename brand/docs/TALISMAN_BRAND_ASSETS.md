# ЖК «Дальневосточный Талисман» — брендовые ассеты

## Статус

Эта папка является источником истины по логотипу и базовой цветовой системе ЖК «Дальневосточный Талисман».

При создании макетов нельзя заменять логотип приблизительно похожей надписью, перерисовывать знак вручную или использовать логотип другого проекта ГК САР.

## Файлы логотипа

### `logo/talisman-logo-primary-transparent.png`
Основной прозрачный логотип из предоставленного мастер-файла.  
Использовать в первую очередь, когда нужен логотип без фона.

### `logo/talisman-logo-dark-gold.png`
Альтернативная версия: золотой знак + тёмно-серая типографика на прозрачном фоне.  
Использовать на светлом фоне при достаточном контрасте.

### `logo/talisman-logo-on-teal.jpg`
Версия логотипа на фирменном бирюзовом фоне.  
Использовать как визуальный референс сочетания цветов и пропорций.

### `logo/talisman-logo-usage-preview.jpg`
Лист с примерами применения вертикальной и горизонтальной компоновок на светлом, бирюзовом и тёмном фоне.  
Использовать как референс выбора версии логотипа.

## Правила использования логотипа

1. Не менять пропорции.
2. Не растягивать по ширине или высоте.
3. Не менять взаимное расположение знака и надписи.
4. Не перерисовывать знак вручную.
5. Не добавлять тени, обводки, свечение и объём.
6. Не помещать логотип на пёстрый фон без достаточного контраста.
7. Не смешивать логотип и визуальную систему «Талисмана» со стилем ЖК «Современник» или другими брендами ГК САР.
8. Если на макете нужен логотип, использовать один из файлов из этой папки, а не создавать текстовую имитацию.

## Важное замечание о цветах

HEX/RGB мастер-цветов выше получены из предоставленных растровых/PNG-файлов.  
Если в исходном векторном брендбуке есть официальные значения HEX / RGB / CMYK / Pantone, они имеют приоритет и должны быть внесены в `talisman-colors.json`.

Сам логотип всегда следует брать из мастер-файла без перекрашивания, если задача не требует официально предусмотренной цветовой версии.

## Инструкция для ИИ

Если задача содержит формулировки:
- «в стиле Талисмана»;
- «по брендбуку Талисмана»;
- «для ЖК Дальневосточный Талисман»;
- «добавь слайд в презентацию Талисмана»;

необходимо сначала использовать файлы из `brand/` как источник истины:
1. логотип — только из `brand/logo/`;
2. цвета — из `brand/tokens/talisman-colors.json`;
3. композиция презентаций — из `brand/docs/TALISMAN_PRESENTATION_STYLE_GUIDE_2025.md`.

При конфликте между произвольным дизайнерским решением и этими файлами приоритет имеют брендовые файлы.
